# st6

Hiring partner project — Gauntlet AI. Engineering take-home: build one small-but-real
application from a menu of five briefs, chosen and scoped by the candidate.

The graded artifact is judgment, not features. Architecture and long-term maintainability
carry the most weight; every performance or correctness claim has to be backed by something
runnable rather than asserted in prose.

- `DECISIONS.md` — required deliverable, ~2 pages, not yet written
